## 从哪里开始

1. **不确定用什么流程** → 打开 **[Skill 收录](skills-catalog.md)**，先选最接近的 **Workflow**
2. **第一次接 MCP** → **[使用说明](usage.md)**
3. **要 clone / 配置** → **[免费下载](download.md)**

## 常见场景（速查）

| 你想做 | 建议 Workflow（在客户端 `workflow_get`） |
|--------|----------------------------------------|
| 小功能 / 修 bug | `/delivery-lite` |
| UI 改版 | `/ui-delivery` |
| 大需求 / 多门禁 | `/feature-delivery` |
| 排障 / 线上问题 | `/incident-response` |
| 发布前检查 | `/release-review` |

完整表与每条说明（含 i18n 文案）以 **[Skill 收录](skills-catalog.md)** 为准（与 `CAPABILITIES.md` 同步）。
