# SEO writing

Make content **findable and readable**. SEO here means matching search intent and structure — not stuffing keywords.

## Workflow

1. **Intent**: informational / navigational / transactional. Match the format (how-to, comparison, reference, landing page).
2. **One primary keyword** per page (plus 2–4 secondary phrases). Write them down first.
3. **Title / H1**: keyword + a specific benefit (≈50–60 chars). The body must deliver it.
4. **First 100 words**: who it's for, what it solves, and the keyword — naturally.
5. **H2s = sub-questions** (long-tail). Each section answers one; tables and lists beat walls of text.
6. **Meta description**: ~150 chars, keyword + promise (GitHub: repo About + topics; docs site: front matter).
7. **Links**: internal links with descriptive anchor text; external links to authoritative sources.
8. **Assets**: image `alt`, code fences with a language, stable slugs.
9. Run the checklist below.

## Do

- Use the reader's words (what they would search), not internal jargon.
- One idea per paragraph; define terms on first use.
- Tables for comparisons; numbered lists for steps.
- Repeat the keyword only where it reads naturally.

## Don't

- No keyword stuffing, hidden text, or HTML-comment keywords (search engines ignore comments).
- No clickbait titles the body doesn't pay off (see `viral-hooks` ethics).
- No duplicate pages competing for the same keyword; consolidate.
- Don't invent facts or numbers as "proof" (see `science-writing`).

## Checklist

- [ ] One primary keyword in the H1 and the first 100 words
- [ ] Title promises something the body delivers
- [ ] Each H2 answers a sub-question
- [ ] Meta description ~150 chars with the keyword
- [ ] Internal links use descriptive text
- [ ] Images have `alt`; code blocks have a language
- [ ] No stuffing, clickbait, or hidden text
