# Writing shape

**Workflow**: `/writing` draft phase (after `writing-beats`).

## Do

The user has passed (or will pass) a markdown file of raw material (any format). Read it end-to-end first.

Run a shaping session that produces a **separate** article document. Do **not** edit the raw material file.

If the user did not say where to save the article, ask once and remember the path.

## Procedure

Follow the loop in `references/shaping-support.md` (prerequisites → openings → grow paragraph by paragraph → append as you go).
