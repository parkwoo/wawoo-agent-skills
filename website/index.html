怎么运作

你只管提需求，剩下的交给「自动化流水线」

无需记忆复杂指令——就像给 AI 配了一位经验丰富的技术总监：

1. 自动派单

你说「帮我修个 Bug」或「做个新功能」，系统识别意图，自动匹配敏捷交付、安全审计、紧急排障等标准工作流。

2. 分步拆解，按需加载

不把 98 份技能书一次性塞给 AI。写代码时只给编码规范，测 Bug 时只给排障指南，精准高效，告别幻觉。

3. 拿证据说话

AI 不能自己宣布「我改好了」。必须拿出测试通过、报错消失等可核对证据，才能进入下一步。

FAQ

常见顾虑，一次说清

这又是一个新的 AI 编程软件吗？

不是。你继续用习惯的 Cursor、Claude Code 或 Codex。wawoo-skills 像挂在后台的 MCP 服务，在关键时刻把正确的规范塞给 AI。

规矩定这么死，复杂需求 AI 会不会变傻？

不会。我们只锁定必须验收的关键节点（例如上线前必须测试）。阶段内部仍可调整顺序、并行任务，你也可以随时打断指挥。

免费吗？能改成公司自己的规范吗？

100% 免费，MIT 开源。Fork 仓库，把团队业务规范写进技能目录，立刻变成你们专属的 AI 研发标准。

会多烧很多 Token 吗？

通常更少。常驻上下文只保留技能目录（约数百 tokens），真正写代码或审计时才 skill_get 加载当步技能；避免一次性塞入上万字 Rules。

会和官方 Agent Rules / Skills 冲突吗？

不替换你的 IDE。MCP 在工具层补充流程与技能；可与现有 .cursorrules 并存，也可逐步把团队规范迁到可版本化的 SKILL.md 与工作流。
