0.7.2 2026-11-18

  • 新增 Skill uplift：强化 accessibility-audit、deployment 的期望清单与静态检查，便于 /ui-delivery 交付时留证据。
  • 新增 web-designer 角色默认路由到 uplift 相关 skill，减少「叫了工作流却不知道拉哪份 SKILL.md」。

0.7.1 2026-11-18

  • 新增 Playwright A/B 框架验证 skill uplift 前后可访问性差异，输出可归档的 JSON 证据（适合 CI 或人工复核）。

0.7.0 亮点版本 2026-11-18

对外可读文档瘦身 + Modern Web Guidance 桥接 + OpenCode MCP 契约 + 会话安全默认收紧——适合从旧版升级时重点阅读。

  • 新增 mwg_search / mwg_retrieve / mwg_legacy_scan：在 Agent 里按需检索现代 Web 指南，不必整库塞进上下文。
  • 客户端 OpenCode 配置示例与 E2E 握手测试；USAGE 同步 Cursor / Claude Code / OpenCode 路径。
  • 护栏 意图会话 resume 默认关闭，仅存最小字段——降低多客户端混用时的上下文泄露风险。
  • 护栏 每步 workflow 标注 replay: safe|unsafe，委派支持幂等键，避免 incident 类流程被误重复执行。
  • 性能 技能体量可测（CAPABILITIES size 列）、上下文压缩与 handoff 契约写进 AGENTS——控制 Token 别爆。
  • 新增 创作向 /writing 工作流；默认入口 agent 更名为 wawoo-auto。
  • 文档 公开面聚焦 README + USAGE + 意图路由；内部审计迁至 internal/，Fork 后更易审阅边界。

0.6.0 亮点版本 2026-10-28

「先说人话 → 自动选 Workflow → 再按阶段 skill_get」成为默认路径；MCP 工具门控防止 Agent 跳过流程直接乱改仓库。

  • 新增 interpret_intent：L0 斜杠命令 / L1 学习库 / L2 上游评分，不确定时回落到人工澄清而非瞎猜 workflow。
  • 新增 workflow_get { phase } 分阶段目标与退出条件；delegate_subtask 带上验收标准。
  • 护栏 意图确认后 mcp_tools_allow 白名单：未跑完审查环不宜直接写生产配置。
  • 客户端 install_global.py 可选开启可写 memory；默认 recall-only 适合只读审代码场景。
  • 修复 pytest 与学习库非确定性、Unix socket 权限、路径遍历判定等 MCP 安全与测试稳定性问题。
